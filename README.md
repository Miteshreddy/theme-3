# Blake & Ryan · Hollow Oak Farm (Theme 03 — Minimal countryside)

Mobile-first React + Vite wedding site.

```
npm install
npm run dev      # http://localhost:5173 (also exposed on your LAN for phone testing)
npm run build    # static output in dist/
```

Content (names, date, schedule, notes, registry links) lives in `src/data.js`.
Photos are in `public/photos/`.
